Native American Ethnobotany

The Native American Ethnobotany (NAEB) database is a treasure. It compiles 45,000 uses of 4000 different plants by 300 Native American Tribes, as recorded in 200 distinct sources. As described on their site, this database was built over decades, starting in the 1970s, spearheaded by the work of Daniel Moerman. You may be interested in Professor Moerman's book Native American Ethnobotany.

About this site

This site provides an alternate unauthorized interface on the NAEB database. It has been reconstructed from the publicly available NAEB site, and no guarantees are made as to its accuracy. This site has no affiliation with the original authors, it is provided in the hope of being useful to future researchers. The original creators and maintainers of the NAEB database deserves all credit for this work. I hope only provide a slight improvement in usability.

Unlike the official NAEB site, this website provides full access to the underlying data. In particular, it allows access to the normalized metadata: categories and subcategories of use, and references. It also provides download capabilities. You can download the full database as a sqlite3 database file , or a zipfile of all the csv files.

Many thanks to the wonderful Datasette tool which powers this website.
