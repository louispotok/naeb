Native American Ethnobotany

About this site

This site provides an alternate interface on the Native American Ethnobotany (NAEB) database, as found here. It has been reconstructed from the publicly available NAEB site, and no guarantees are made as to its accuracy. This site has no affiliation with the original authors, it is provided in the hope of being useful to future researchers. The NAEB database is due to Daniel Moerman, who deserves all credit for this research. You may be interested in Professor Moerman's book Native American Ethnobotany.

Unlike the main NAEB site, this website provides full access to the underlying data. In particular, it allows access to the normalized metadata: categories and subcategories of use, and references. It also provides download capabilities. You can download the full database as a sqlite3 database file , or a zipfile of all the csv files.

Many thanks to the wonderful Datasette tool.
